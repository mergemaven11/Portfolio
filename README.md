## Run Locally

```bash
git clone https://github.com/mergemaven11/Portfolio.git
cd Portfolio
yarn install
yarn start
```

The development server runs locally and reloads as changes are made.

## Production Build

```bash
yarn build
```

The optimized production output is written to the `build` directory.
